## 概览

QeEdu 可以按三种部署方式说明：

- Cloud：官方托管服务，适合快速体验。
- Community：社区版自部署，适合学习、二次开发和轻量试点。
- Education：教育版私有化部署，适合校内数据和定制交付。

## 组件

当前产品通常包含前端、API 网关、用户服务、AI 聊天服务、智能体协作服务、沙箱服务和数据库等组件。

Community 自部署使用 `docker/docker-compose.release.yaml`，从 GHCR 拉取公共镜像：

```text
ghcr.io/turmwerk/qeedu-web
ghcr.io/turmwerk/qeedu-gateway
ghcr.io/turmwerk/qeedu-user-services
ghcr.io/turmwerk/qeedu-sandbox
ghcr.io/turmwerk/qeedu-ai-chat
ghcr.io/turmwerk/qeedu-ai-copilot
```

已验证公共测试标签为 `test-ce-20260604`。

## 环境

不同部署方式需要明确：

- 前端域名，例如 `qeedu.tech` 或 `cloud.qeedu.tech`。
- API 域名，例如 `api.qeedu.tech`。
- OAuth 回调地址。
- 数据库和模型供应商配置。
- Cookie、跨域和 HTTPS 策略。
