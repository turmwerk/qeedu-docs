## 概览

QeEdu API 用于支撑前端、智能体调用、知识库管理、用户认证和后续系统集成。当前文档先说明方向，详细接口会随产品稳定后逐步补齐。

## 当前重点

- 用户登录与 OAuth 回调。
- 智能体任务创建与会话。
- 知识库导入、检索和更新。
- 文件导出和运行日志。

## 集成方向

教育版可以根据学校需求对接统一身份认证、模型网关、对象存储、内部知识库或已有业务系统。但集成应从低风险读写开始，逐步扩大范围。
