## 概览

最快的体验方式是打开 `https://cloud.qeedu.tech`，使用已部署的云端产品完成登录、创建任务、调用智能体和查看结果。

如果需要本地运行，可以使用社区版仓库：

```bash
git clone https://github.com/turmwerk/qeedu.git
cd qeedu
```

具体后端、前端和模型配置会在后续文档中补齐。

## Cloud 体验流程

1. 进入 QeEdu Cloud。
2. 登录账号。
3. 选择一个高校事务场景，例如通知草拟、课程材料生成或学生事务问答。
4. 输入任务背景和约束条件。
5. 查看生成结果，并按学校真实语境进行人工确认。

## 试点建议

优先选择低风险、高重复、容易评价的任务。不要一开始就承诺全校全系统替代，也不要把 AI 输出直接作为正式文件发布。
